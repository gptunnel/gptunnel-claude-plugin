# GPTunneL for Claude

Organize your [GPTunneL](https://gptunnel.ru) media library and design node workflows from Claude.

- Find past results and sort them into collections.
- Find a ready workflow template, copy it to your account and fill in your inputs.
- Build a new workflow from a description, or explain and fix an existing one.
- Upload files to GPTunneL for your workflows.

Nothing in this plugin spends your balance: workflows are run in the GPTunneL editor on gptunnel.ru, where you see the cost.

## Install

In Claude Code, once the plugin is in the directory: `/plugin install gptunnel@claude-plugins-official`. In Claude apps: Settings → Connectors → GPTunneL.

Sign-in happens in the browser on gptunnel.ru (OAuth); there is nothing to copy. The plugin connects to `https://gptunnel.ru/mcp/claude` and asks only for workflow and library access.

## Data

The plugin talks only to `gptunnel.ru`. Workflows, uploaded files and the library are stored in your GPTunneL account, as when you use the website.
